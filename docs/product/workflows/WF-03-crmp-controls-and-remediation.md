# CRMP Controls and Remediation

- **Trigger/precondition:** Applicable approved obligation.
- **Primary flow:** Control assessment → adequacy → gap → action → owner/date → execution → closure readiness.
- **Exceptions:** Missing owner/date, blocked action, overdue, target-date change.
- **Screens:** SCR-002, SCR-010, SCR-011, SCR-012

## Transition requirements
Every transition is server-authorized, version-aware, auditable and idempotent for repeated integration delivery. The detailed state/action matrix must be represented in application tests and Azure DevOps Test Plans.
