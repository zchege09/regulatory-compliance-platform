# Remediation Closure

- **Trigger/precondition:** Owner considers remediation complete.
- **Primary flow:** Evidence → Ready for Closure → independent validation → residual risk → close or return.
- **Exceptions:** Missing/insufficient evidence, ineffective control, high residual risk.
- **Screens:** SCR-011, SCR-012, SCR-013, SCR-014

## Transition requirements
Every transition is server-authorized, version-aware, auditable and idempotent for repeated integration delivery. The detailed state/action matrix must be represented in application tests and Azure DevOps Test Plans.
