# Amendment Reassessment

- **Trigger/precondition:** New version of approved publication.
- **Primary flow:** Version detected → impact review → affected records → no-impact decision or reassessment/reapproval.
- **Exceptions:** Ambiguous impact, effective-date change, no material impact.
- **Screens:** SCR-003, SCR-004, SCR-006, SCR-013

## Transition requirements
Every transition is server-authorized, version-aware, auditable and idempotent for repeated integration delivery. The detailed state/action matrix must be represented in application tests and Azure DevOps Test Plans.
