
## Product design specifications
See `docs/product/` for screens, workflows, permissions, notifications and SLA rules. ADR-014 through ADR-017 define workflow, approval, source processing and audit decisions.

## Workflow test traceability
Workflow specifications in `docs/product/WORKFLOW-CATALOGUE.md` are mapped to requirements, user stories and test cases under `docs/testing/` and `devops/test-plans/`. New workflow behaviour must update this traceability in the same change.
